# ⌨️ Data Entry

> Learn the correct techniques for entering, editing, and managing data in Microsoft Excel. Efficient data entry is the foundation of clean, reliable, and accurate analysis.

---

# 📖 Overview

Every dashboard, Pivot Table, formula, and report starts with **data entry**.

If the data entered into Excel is incorrect or inconsistent, every analysis built on top of it becomes unreliable.

Professional Data Analysts spend considerable time ensuring data is entered correctly before beginning any analysis.

---

# 🎯 Learning Objectives

By the end of this lesson, you will be able to:

- Enter different types of data correctly
- Edit existing data efficiently
- Use AutoFill and Flash Fill
- Copy and move data
- Insert and delete rows and columns
- Avoid common data entry mistakes
- Follow professional data entry practices

---

# 📚 What is Data Entry?

Data Entry is the process of entering information into an Excel worksheet.

Examples include:

- Employee records
- Customer information
- Sales transactions
- Inventory details
- Financial reports
- Survey responses

Accurate data entry is the first step toward meaningful analysis.

---

# 📊 Types of Data You Can Enter

Excel supports multiple data types.

| Data Type | Example |
|-----------|---------|
| Text | Rahul Sharma |
| Number | 1250 |
| Currency | ₹15,000 |
| Percentage | 25% |
| Date | 15-Jul-2026 |
| Time | 10:30 AM |
| Formula | `=SUM(B2:B20)` |

# ✍️ Entering Data

Click any cell and begin typing.

Example:

| A | B | C |
|---|---|---|
| Employee ID | Name | Salary |
| 101 | Rahul | 50000 |
| 102 | Priya | 65000 |

Press:

- **Enter** → Move down
- **Tab** → Move right
- **Shift + Enter** → Move up
- **Shift + Tab** → Move left

---

# ✏️ Editing Data

To edit a cell:

### Method 1

Double-click the cell.

### Method 2

Select the cell and press:

```text
F2
```

### Method 3

Edit directly in the Formula Bar.

---

# 📋 Copying Data

Copy data using:

```text
Ctrl + C
```

Paste using:

```text
Ctrl + V
```

Excel copies:

- Values
- Formulas
- Formatting
- Comments (if applicable)

---

# ✂️ Cutting Data

Move data instead of copying.

Shortcut:

```text
Ctrl + X
```

Paste:

```text
Ctrl + V
```

---

# 📥 Drag and Drop

Move data by:

1. Selecting the cells.
2. Placing the cursor on the border.
3. Dragging the selection to a new location.

Hold **Ctrl** while dragging to create a copy instead of moving the data.

---

# 🔄 AutoFill

AutoFill helps repeat patterns automatically.

Example:

```text
January
February
```

Drag the fill handle downward.

Excel continues:

```text
March
April
May
...
```

AutoFill also works for:

- Numbers
- Dates
- Weekdays
- Months
- Formulas

---

# ⚡ Flash Fill

Flash Fill automatically recognizes patterns.

Example:

| Full Name | First Name |
|-----------|------------|
| Rahul Sharma | Rahul |
| Priya Patel | Priya |

After typing the first result, press:

```text
Ctrl + E
```

Excel fills the remaining values automatically.

Flash Fill is useful for:

- Extracting names
- Combining text
- Splitting data
- Formatting phone numbers

---

# ➕ Inserting Rows

To insert a new row:

```text
Ctrl + Shift + +
```

# 💼 Real-World Business Example

Suppose you're entering employee records.

| Employee ID | Name | Department | Salary |
|------------:|------|------------|-------:|
| 101 | Rahul Sharma | Sales | 55000 |
| 102 | Priya Patel | HR | 62000 |
| 103 | Amit Singh | Finance | 58000 |

Professional analysts ensure:

- Employee IDs are unique.
- Department names are consistent.
- Salary values are numeric.
- No blank rows exist within the dataset.

---

# 💡 Best Practices

- Enter one record per row.
- Keep one attribute per column.
- Use consistent spelling.
- Avoid unnecessary blank rows.
- Use AutoFill for repetitive data.
- Verify entries before analysis.
- Save your work frequently.

---

# ⚠️ Common Mistakes

❌ Mixing multiple values in one cell.

❌ Leaving blank rows within a dataset.

❌ Typing numbers as text.

❌ Using inconsistent date formats.

❌ Entering duplicate records.

❌ Copying formulas without checking references.
