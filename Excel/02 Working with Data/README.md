# 📊 Working with Data

> Learn how to enter, organize, format, validate, and manage data efficiently in Microsoft Excel. This module introduces the essential techniques used by Data Analysts to prepare datasets before performing analysis.

---

# 📖 Overview

Data is the foundation of every analysis.

Before you can build dashboards, create Pivot Tables, or generate business insights, your data must be **accurate**, **consistent**, and **well-organized**.

In this module, you'll learn how to work with datasets professionally by mastering data entry, formatting, sorting, filtering, validation, and workbook organization.

These are the same skills used daily by Data Analysts, Business Analysts, Financial Analysts, and Operations teams.

---

# 🎯 Learning Objectives

By the end of this module, you will be able to:

- Enter data efficiently
- Use different types of cell references
- Format worksheets professionally
- Apply number formatting
- Create and manage Excel Tables
- Work with Named Ranges
- Freeze rows and columns
- Sort and filter datasets
- Apply advanced filtering
- Validate user input
- Protect workbook contents

Real-world datasets are rarely ready for analysis.

- Entering new data
- Correcting formatting issues
- Standardizing values
- Organizing information
- Validating inputs
- Preparing datasets for analysis

Mastering these skills ensures your data remains clean, consistent, and reliable.

# 💡 Best Practices

- Keep one record per row.
- Keep one attribute per column.
- Use consistent formatting throughout the worksheet.
- Convert datasets into Excel Tables whenever possible.
- Validate user input before analysis.
- Avoid blank rows inside datasets.
- Use meaningful column headers.
