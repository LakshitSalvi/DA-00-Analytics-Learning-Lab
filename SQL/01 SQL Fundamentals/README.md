# SQL Fundamentals

## Overview

SQL Fundamentals is the foundation of working with relational databases. Before learning advanced concepts like Joins, Window Functions, and Common Table Expressions (CTEs), it is essential to understand how to retrieve, display, and manipulate data using basic SQL queries.

This section contains beginner-friendly SQL exercises designed around real-world business scenarios commonly encountered by Data Analysts.

---

## Learning Objectives

After completing this section, you will be able to:

- Retrieve data from database tables
- Select specific columns
- Remove duplicate values using `DISTINCT`
- Rename columns using aliases
- Display a limited number of records
- Perform basic calculations
- Handle `NULL` values
- Combine multiple columns into a single output
- Sort data using `ORDER BY`
- Understand the logical execution order of SQL queries
